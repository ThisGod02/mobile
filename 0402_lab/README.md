### Цель
Выполнить требования лабораторной работы и закрепить основы Compose Navigation.

### Реализовано
Три экрана с Navigation Compose, передачей имени пользователя через аргумент маршрута, переходами назад и системным BackHandler.

### Технологии
Android Studio, Kotlin, Jetpack Compose, Navigation Compose.

### Запуск
Откройте папку в Android Studio, дождитесь Gradle Sync и запустите app на эмуляторе Android 7.0+.

### Сложности и решения
Состояние UI и обработчики разделены на небольшие компоненты; Использованы API, соответствующие теме задания. Для запуска Android-проекта необходимы Android SDK 35 и JDK 17 или новее.
