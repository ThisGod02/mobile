### Цель
Выполнить требования лабораторной работы и закрепить основы TaskFlow.

### Реализовано
Итоговое приложение задач: два навигационных экрана, Room-хранилище, ViewModel/StateFlow, создание, отметка выполнения и удаление задач.

### Технологии
Android Studio, Kotlin, Jetpack Compose, Room, Navigation Compose, MVVM, StateFlow.

### Запуск
Откройте папку в Android Studio, дождитесь Gradle Sync и запустите app на эмуляторе Android 7.0+.

### Сложности и решения
Состояние UI и обработчики разделены на небольшие компоненты; Использованы API, соответствующие теме задания. Для запуска Android-проекта необходимы Android SDK 35 и JDK 17 или новее.
