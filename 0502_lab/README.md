### Цель
Выполнить требования лабораторной работы и закрепить основы Compose Counter.

### Реализовано
MVVM-счётчик на immutable CounterState и StateFlow: инкремент/декремент, выбор шага, сброс и асинхронная загрузка. UI подписан через collectAsStateWithLifecycle.

### Технологии
Android Studio, Kotlin, Jetpack Compose, ViewModel, StateFlow, Coroutines.

### Запуск
Откройте папку в Android Studio, дождитесь Gradle Sync и запустите app на эмулятор Android 7.0+.

### Сложности и решения
Состояние UI и обработчики разделены на небольшие компоненты; Использованы API, соответствующие теме задания. Для запуска Android-проекта необходимы Android SDK 35 и JDK 17 или новее.
