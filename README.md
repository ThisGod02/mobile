# Лабораторные работы по мобильной разработке

В репозитории подготовлены отдельные папки с реализациями лабораторных работ. В каждой папке находится исходный файл задания `*_lab.md`, код решения и `README.md` с отчётом и инструкцией запуска.

| Папка | Тема | Запуск |
|---|---|---|
| `0102_lab` | Первое приложение Jetpack Compose | Android Studio |
| `0202_lab` | Kotlin: синтаксис, null-безопасность, коллекции, корутины | IntelliJ IDEA / Gradle |
| `0302_lab` | Интерактивный профиль на Compose | Android Studio |
| `0402_lab` | Жизненный цикл и Navigation Compose | Android Studio |
| `0502_lab` | MVVM и StateFlow | Android Studio |
| `0602_lab` | Room и локальные заметки | Android Studio |
| `0702_lab` | Retrofit и сетевой запрос | Android Studio + интернет |
| `0802_lab` | PWA To-Do List, Service Worker, Capacitor | Node.js / браузер |
| `0902_lab` | Итоговый TaskFlow: Room + Navigation + MVVM | Android Studio |

## Общая проверка

- Android-проекты открываются в Android Studio с JDK 17+ и Android SDK 35.
- Kotlin-проект запускается с JDK 17+ через Gradle.
- PWA запускается через локальный HTTP-сервер, чтобы Service Worker был активен.
