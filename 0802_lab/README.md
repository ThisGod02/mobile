## Запуск в браузере
Service Worker требует `localhost` или HTTPS. Из этой папки выполните `npm install`, затем `npm start`; откройте адрес локального сервера, напечатанный в терминале. Проверка офлайна: загрузить страницу один раз, затем отключить сеть в DevTools и обновить.

## Android через Capacitor
После `npm install` выполните `npx cap add android`, затем `npm run cap:sync` (скрипт подготовит `www/` и синхронизирует файлы) и `npm run cap:open`. В Android Studio соберите APK. SDK и Android Studio должны быть установлены.

- `capacitor.config.json`, `package.json` — упаковка в Android.
