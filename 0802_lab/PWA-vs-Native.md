# PWA и нативное приложение

| Критерий | PWA | Нативное Android-приложение |
|---|---|---|
| Разработка | HTML/CSS/JS, одна web-сборка | Kotlin/Compose, Android SDK |
| Установка | Из браузера, без магазина | APK/Google Play |
| Офлайн | Service Worker + Cache Storage; данные localStorage | Полный доступ к локальному хранилищу |
| Возможности устройства | Ограничены поддержкой браузера/плагинов | Широкий доступ к API Android |
| Обновления | Публикация на сервере | Обновление приложения |
| Подходящий сценарий | Контент и простой кроссплатформенный сервис | Сложный интерфейс, производительность и глубокая интеграция |

Для списка задач PWA достаточна: она быстро запускается, работает офлайн и не требует установки из магазина.
