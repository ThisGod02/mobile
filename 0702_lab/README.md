### Цель
Выполнить требования лабораторной работы и закрепить основы Retrofit Catalog.

### Реализовано
Кнопка загружает список задач из JSONPlaceholder; результат отображается в Compose LazyColumn, предусмотрены состояния загрузки и ошибки.

### Технологии
Android Studio, Kotlin, Jetpack Compose, Retrofit, Gson, Coroutines.

### Запуск
Откройте папку в Android Studio, дождитесь Gradle Sync и запустите app на устройстве/эмуляторе с интернетом.

### Сложности и решения
Состояние UI и обработчики разделены на небольшие компоненты; Использованы API, соответствующие теме задания. Для запуска Android-проекта необходимы Android SDK 35 и JDK 17 или новее.
